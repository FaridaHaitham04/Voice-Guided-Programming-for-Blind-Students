# EchoCode

Voice-guided programming for blind students.

## Sign in page

The app currently includes the EchoCode welcome/sign-in screen:

- Sign in with voice (browser speech recognition when available)
- Sign in with email and password
- Screen-reader announcements as password characters are typed
- Create-an-account view

## Run locally

You need Node.js 18 or later.

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).
